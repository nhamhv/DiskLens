DiskLens

See what is taking up space on your Mac or Linux PC, and clean it up safely.

Open source · Tauri + Rust + React · Apache-2.0
DiskLens — Home
Start

One place to begin

  • Home or Whole Disk in one click, or drop any folder on the window.
  • Previous scans open instantly. Rescan only when you want to.
  • Hidden space (purgeable, Time Machine snapshots) is shown too.
  • Speed modes from Minimum to Fast keep your Mac responsive.
DiskLens
Scan

Every tile stays visible

  • Treemap or bubbles of any folder. Click a tile to drill in.
  • Small folders don't vanish next to a 200 GB one.
  • Colour by kind or by safety. Safe-to-clean folders carry a ✨.
  • Low CPU mode scans at background priority.
DiskLens — Home
Drill down

From the disk to the culprit

  • Open Library and see caches, Xcode data and containers by size.
  • Right-click to reveal in Finder, copy the path or delete.
  • Each item shows how much it grew since the last scan.
DiskLens — Library
Cleanup

Safe to clean, in one list

  • Caches, build output, node_modules, DerivedData: 67 GB in this sample.
  • Safety comes from an allowlist, so unknown folders are never marked safe.
  • Move to Trash asks once. Delete permanently asks twice. System folders are always refused.

Largest files

Find the big ones

  • The biggest files and folders under the current folder, largest first.
  • Filter to files untouched for a year or more.
  • Select several and remove them in one go.

Changes

What grew since last time

  • Every folder shows a delta against the previous scan.
  • The Changes tab lists the biggest growth and shrinkage first.
  • Quickly spot the cache or container that ate 8 GB this week.
DiskLens — Changes
Developer

Clean up after your toolchain

  • Projects: node_modules, target, .venv, Pods, build folders.
  • SDKs, package caches, editors, AI tools and old versions in their own tabs.
  • Each item is Safe, Rebuild (with the command to bring it back) or Caution.
  • Git worktrees are checked for uncommitted work. A rules file lets you add your own.

Photos

Keep the best shot

  • Blurry photos, screenshots and near-identical shots.
  • In each similar group the sharpest, largest photo is the one to keep.
  • Everything is analysed on your Mac. Nothing is uploaded.
